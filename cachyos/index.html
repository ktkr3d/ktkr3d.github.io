CachyOSの設定

ダウンロード

https://cachyos.org/ からISOイメージをダウンロードしてインストールメディアを作成します。私はVentoyを使いました。

インストール

  • ブートローダはLimineを選択
  • Limine用パーティション(8GB, fat32, /boot)
  • CachyOS用パーティション(400GB, btrfs, /)
  • WM/DE はHyprlandを選択
  • 既存のNTFSのリサイズでエラーが発生する場合はNTFSをCHKDSK /f

ユーザディレクトリ

  • ユーザディレクトリを英語名に変更

パッケージ管理

  • shelly
    GUI版からAURとflatpakを有効化

Hyprlandの設定

HyprModで設定します。

ディスプレイ (Monitors)

  • 必要に応じて解像度、拡大率等を変更

キーボード (Devices > Keyboard)

  • 事前準備
  • 日本語キーボードの追加
    Keyboard layoutsのAdd layoutでjp Defaultを追加した後でjpを一番上にドラッグ

マウスカーソル (Cursor)

  • マウスカーソルのテーマをAdwaitaに変更
    Theme > CursorでAdwaitaを選択
    General > Enable HyprCousor をオフ

自動起動 (Autostart)

  • fcitx5を自動起動に追加

環境変数 (Env Variables)

  • fcitx関連の環境変数を追加

    Name Value
    XMODIFIERS @im=fcitx
    QT_IM_MODULE fcitx
    GTK_IM_MODULE fcitx
    TERM linux
    TERMINAL kitty

その他 (Miscellaneous > Startup)

  • Hyprland起動時の表示を無効化
    Disable Hypyland logo : on
    Disable splash rendering : on

キーバインド (Keybinds)

  • キーバインドの表示と変更（⭐：よく使うもの）

    Mod + Key(s) Action
    Super Enter kitty
    E⭐ thunar
    T⭐ kitty
    C⭐ code
    W⭐ google chrome
    Z⭐ noctalia settings
    X noctalia control-center
    Space⭐ launcher
    . launcher /emo
    L lock
    ALT+C session menu
    SHIFT+W wallpaper
    V⭐ clipboard
    A notification
    Q⭐ close window
    ALT+Space floating
    D⭐ fullscreen (mode=1)
    F fullscreen
    J split
    SHIFT + S⭐ special workspace
    S⭐ scratchpad
    M⭐ hyprmod

Noctaliaの設定

Noctaliaの設定機能を使います。
Super+Zで起動します。

テンプレート

  • 内蔵 > GTK 3のチェックをオフ

    Thunarの色が不自然になったためワークアラウンド

ロック画面

  • ウィジェットでロック画面に時計やカレンダーを配置

OSD

  • 種類から変更
    キーボード配列: off

バー :default

  • バーを右に配置
    General > position : right
  • ウィジェットの配置カスタマイズ
    Widget List で各ウィジェットの有無と位置を設定
    各ウィジェットの設定は各ギアボタンを押下
  • clockウィジェットの日付時刻書式変更

Bookmarks (コミュニティ)

  • 改行なしのJSON形式で保存される。
  • 整形してcodeで編集するコマンド
  • ブックマークアイコンの変更
    ファイル内のglyphの値を変更する。指定可能なアイコンは以下を参照。
    https://tabler.io/icons
  • デスクトップアプリの起動コマンド
    いくつか方法があります。最適な方法を選択します。
    GUIアプリはバックグラウンドをオンにすると安定する場合があります。
  • シェルスクリプト（常駐系）
    tasksという特殊ワークスペースで実行。移動はしない。 特殊ワークスペースをトグルするコマンド
  • シェルスクリプト（TUI）
  • リモートのディレクトリをThunarで開くコマンド または
  • リモートのディレクトリをvscodeで開くコマンド
