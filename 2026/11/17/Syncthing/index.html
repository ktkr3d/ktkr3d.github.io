Syncthing

Created2026-11-17|Updated2026-11-17

Syncthingは、中央のサーバーを介さず、デバイス同士を直接接続してファイルをリアルタイムに自動同期する、無料のオープンソース・P2P（ピアツーピア）ファイル同期ソフトウェアです。
NoctaliaプラグインNotesのデータを複数のPCLAN間で同期してみました。

https://syncthing.net/

環境

構成は以下の通り。3台すべて同じLANに接続。

  • 同期対象のPC
    • Desktop PC ( CachyOS / Hyprland / Noctalia )
    • Notebook PC ( Arch Linux / Hyprland / Noctalia )
    • Headless PC ( Arch Linux / Hyprland / Noctalia )
  • 同期対象フォルダ
    • ~/Documents/Notes
  • 同期ソフト
    • syncthing 2.1.7

構築

3台すべてのPCで、以下の手順を実行してSyncthingのインストールと自動起動の設定を行います。

パッケージのインストール

公式リポジトリから syncthing をインストールします。

サービスの有効化（ユーザー単位）

ログイン時にバックグラウンドで自動起動するよう、systemdのユーザーサービスを有効化します。sudo は不要です。

実行

初期設定とデバイス・フォルダの紐付け

各PCでサービスが起動したら、ブラウザで http://localhost:8384 にアクセスしてWeb UIから設定を行います。

デバイス同士の接続（全3台をフルメッシュ接続）

3台のどこで編集しても即座に他2台へ反映されるよう、互いにデバイスIDを登録します。

  1. 各PCのWeb UI右上「操作」＞「IDを表示」からデバイスIDを確認する。
  2. 他のPCのWeb UI右下「リモートデバイスを追加」をクリックし、IDと分かりやすいデバイス名を入力して保存する。
  3. 相手側の画面上部に承認バナーが出るので「デバイスを追加」をクリックして承認する。
  4. これを3台の総当たり（A-B、B-C、A-C）で行う。

同期フォルダの設定

~/Documents/Notes を同期対象として登録します。

  1. まず1台目のWeb UI左側「フォルダを追加」をクリックする。
  2. フォルダラベル: noctalia-notes（任意）
  3. フォルダID: noctalia-notes（3台で共通のIDにする）
  4. フォルダパス: ~/Documents/Notes
  5. 「共有」タブを開き、接続済みの残り2台のデバイスにチェックを入れて「保存」する。
  6. 残り2台のWeb UIに「新しいフォルダの共有リクエスト」が表示されるため、「追加」をクリックし、パスを ~/Documents/Notes に指定して保存する。

利用

設定完了後、数秒で初回スキャンと同期が完了し、Web UI上のステータスが「最新」になります。

実際の使用感と運用ポイント

  • 圧倒的な同期速度
    LAN内通信のため、数KBのファイルであれば保存した瞬間に他の2台へ反映されます。
  • 競合ファイルの扱い
    オフラインで別々のPCから同じファイルを編集した場合、sync-conflict という名前が付いたファイルが自動生成されるため、データ消失の心配がありません。
  • GUI管理の簡便さ
    普段はブラウザを開く必要すらなく、裏で静かに動き続けてくれます。状態を確認したい時だけ http://localhost:8384 を開けば十分です。
