Noctalia Jellyfin Browser

Created2026-10-12|Updated2026-10-24

Jellyfinサーバに接続してライブラリをブラウズするNoctaliaプラグインを作成しました。MPVで再生します。

https://github.com/ktkr3d/noctalia-plugins
https://github.com/ktkr3d/noctalia-plugins/tree/main/jellyfin-browser

環境

ソフトウェア構成

  • Arch Linux
    • Hyprland
    • mpv 0.41.0
    • Noctalia 5.2.1
      • Jellyfin Browser プラグイン 0.0.4
    • socat 1.8.1.3

構築

前提パッケージ

  • インストール

プラグイン発行元を追加

  • コマンドの場合

  • GUIの場合
    Noctaliaの設定画面(Spuer+Z)のプラグインメニューからプラグイン発行元を追加します。

    項目 値
    分類 Git
    発行元ID ktkr3d
    位置情報 https://github.com/ktkr3d/noctalia-plugins

プラグインの有効化

  • コマンドの場合
  • GUIの場合
    Noctaliaの設定画面(Spuer+Z)のプラグインメニューから一覧にあるJellyfin Browserプラグインを有効(スイッチをオン)にします。

ウィジェットの追加

Noctaliaの設定画面(Spuer+Z)のBar: defaultメニューからウィジェットリストを選択してJellyfin Browerウィジェットを追加します。

利用

起動

  1. パネルを開きます。
  2. Jellyfinサーバにログインします。(初回のみ)
    • サーバURL
    • ユーザ名
    • パスワード
  3. ライブラリを検索します。
  4. メディアのPlayを押します。MPVで再生されます。

バックグラウンドで動画再生を継続するには

動画はMPVによりフォアグラウンドで再生されます。スペシャルワークスペースに移動させます。

  1. メディア再生
  2. Super+Shift+S
  3. Super+S
    バックグラウンドで再生が継続します。
  4. フォアグラウンドに戻すには、Super+S

カスタマイズ

プラグインのカスタマイズ

プラグインの右側の⚙️から設定します。
ウィジェットのラベル表示を切り替えたりできます。

ウィジェットのカスタマイズ

追加したウィジェットの右側の⚙️から設定します。
パネルをバーに接着したりできます。

キーバインド

HyprModなどを使ってキーバインドすると便利です。

  • Jellyfin Browserパネル
    Super+B
  • Noctaliaコントロールセンタのメディアパネル
    Super+Sfift+B
