WoW OnUseGear Addon

Created2026-08-15|Updated2026-08-18


https://github.com/ktkr3d/OnUseGear

装備しているアイテムの中で使用(Use)できるものをアクションボタン化するアドオンを作成しました。
対象はトリンケットだけではなく、武器や防具で使用できるものを含めて自動的に列挙します。

導入

インストール

https://wowup.io/guide/get-addons/overview
Install from URLの手順でGitHubのリポジトリURLを指定してインストールします。

  1. WowUpを起動
  2. 左のサイドメニューからGet Addons
  3. 右上のInstall from URL
  4. Install Addon URLダイアログでhttps://github.com/ktkr3d/OnUseGearを指定
  5. Import
  6. Install
  7. Close

アップデート

WowUpでアップデートできます。

利用

  1. 初回ログイン時、画面中央にOnUserGearのアクションボタンが配置されます。トリンケットなど装備中の使用可能なアイテムが列挙されます。
  2. マウスをアクションボタンにホバーするとボタンの左上にオレンジのハンドルが表示されるのでドラッグして任意の位置に移動します。
  3. ミニマップボタンまたは/ougコマンドから設定画面を開いてボタンのサイズを調整し、位置をロックします。OnUseGearのミニマップボタンを右クリックしてボタンの位置をロックすることもできます。
  4. アクションボタンをクリックすると装備中のアイテムを使用できます。使用後、ボタン上にクールダウン時間がカウントダウン表示されます。
  5. WoWオプション画面のKeybindingsからキーバインドを設定できます。
  6. 複数キャラクタがいる場合、設定画面から別のキャラクタのプロファイル(設定内容)を指定することができます。

設定

設定画面

設定画面の表示方法

  • ミニマップアイコンから
    ミニマップアイコンを左クリック
  • スラッシュコマンドから
  • WoWのオプション画面から
    Esc > Options > AddOns > OnUseGear

ロック状態の切り替え方法

  • ミニマップアイコンから
    ミニマップアイコンを右クリック
  • スラッシュコマンドから
  • OnUseGearの設定画面から
    Lock Action Barをチェック

キーバインドの設定方法

  • WoWのオプション画面から
    Esc > Options > Game > Keybindings > OnUseGear
