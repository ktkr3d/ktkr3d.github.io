oUF MyLayout Addon v0.3.0

Created2026-08-09|Updated2026-08-31

https://github.com/ktkr3d/oUF_MyLayout

oUF MyLayoutアドオンに機能追加しました。

  • ミニマップボタン
  • テストモード

追加内容

設定画面

ミニマップボタン

ミニマップ上にoUF_MyLayoutアドオンのアイコンを表示します。左クリックで設定画面を表示します。右クリックでテストモードをトグルします。

テストモード

パーティフレーム、ボスフレーム、メインタンクフレーム、レイドフレームをテスト表示します。
ミニマップボタンを右クリックするか、設定画面でテストモードをトグルします。

導入

インストール

https://wowup.io/guide/get-addons/overview
Install from URLの手順でURLからインストール

  1. WowUpを起動
  2. 左のサイドメニューからGet Addons
  3. 右上のInstall from URL
  4. Install Addon URLダイアログでhttps://github.com/ktkr3d/oUF_MyLayoutを指定
  5. Import
  6. Install
  7. Close

アップデート

  • fix: raidユニットフレームにマウスホバーでツールチップが表示されない v0.3.5
  • fix: テストモードのユニット(boss, maintank)にマウスホバーでエラー v0.3.5
  • fix: テストモードを解除してもraidユニットフレームの表示内容が通常に戻らない v0.3.5
  • fix: ターゲットフレームがプレイヤーかプレイヤーのペットの場合、テストモードの終了後に描画が不正になる v0.3.6
  • feat: 動的raidユニットフレーム機能実装(グループ数が5を超えた際に全体幅を固定化) v0.3.7

Open

その他

deployスクリプト

  • 開発中のコードをゲームのAddonフォルダにデプロイします。lib、mediaはほぼ固定なのでデプロイは省略しています。

releaseスクリプト

  • Githubにリリースするために現在のコード/リソースをアーカイブします。.tocファイル内のバージョン番号を更新してから実行します。
