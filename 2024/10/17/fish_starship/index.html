fish + starship

Created2024-10-17|Updated2026-08-30

fish(friendly interactive shell)はユーザフレンドリーなコマンドラインシェルです。シェルをfishに切り替えてみました。
またプロンプトを装飾するためにStarshipを使ってみました。

2026-08-30

  • Caelestiaのstarship.tomlを利用する手順

    1. ダウンロード
    1. イタリック体を解除する場合

  2. Starshipのインストール

    • Windows Terminalからコマンドプロンプト起動時のWindowsロゴ表示を抑止するには
      go to windows terminal> settings> command prompt> command line and add /k in the end.
      ex: %SystemRoot%\System32\cmd.exe /k
    • Windows TerminalからPowerShell起動時のWindowsロゴ表示を抑止するには
      ex: pwsh -nologo
      ex: “C:\Program Files\PowerShell\7\pwsh.exe” -nologo
